# Arı Yabancı Dil

Flutter ile yazılmış yabancı dil uygulaması iskeleti.

## Yapı

```
lib/
├── main.dart
└── screens/
    ├── home_screen.dart       # Ana sayfa: başlık + ayar ikonu + Dersler butonu
    ├── settings_screen.dart   # Boş ayarlar menüsü
    └── dersler_screen.dart    # Boş dersler ekranı
```

## Çalıştırma

```bash
flutter create .       # platform klasörlerini üret (lib/ ezilmez)
flutter pub get
flutter run
```
